# Gobernanza — Medicina Integral

Repositorio público de la documentación de gobernanza del proyecto **Medicina Integral**: marco sistemático para el estudio de cualquier tema médico y elaboración de documentos clínicos (guías, revisiones, informes, presentaciones y casos clínicos) al estándar editorial de una publicación médica de excelencia.

## Contenido

| Archivo | Descripción |
|---|---|
| `AGENTS.md` | Directivas permanentes de operación (gobernanza v2.0): principio de excelencia editorial, confidencialidad de la configuración, principios de contenido, versionado y control de cobertura. |
| `MEDICINA_INTEGRAL.md` | Marco sistemático (v1.1): nota metodológica, doce dominios temáticos, eje temporal del análisis, criterios de aplicabilidad por tipo de tema, criterios de calidad de la evidencia (jerarquía N1–N4, GRADE, herramientas de riesgo de sesgo, vigencia) y estructura estándar del documento clínico. |
| `PLANTILLA_CONTRAPUNTO.md` | Plantilla de informe crítico de vanguardia (v1.0): cegueras del paradigma, variables infranegligidas, hechos incómodos, señales emergentes, escala de sustento ampliada (N1–N4, señal, hipótesis, laguna) y protocolo de refutación interna. |
| `REGISTRO_VERSIONADO.md` | Registro interno de versiones de la gobernanza, plantillas y análisis producidos. |

## Principios rectores

1. **Excelencia editorial:** todo entregable se sostiene por su calidad científica y editorial ante un lector externo; ninguna entrega expone la configuración ni las reglas internas de operación.
2. **Integración biopsicosocial:** el fenómeno clínico se analiza como nodo de interacción entre sistemas biológicos, psicológicos y sociales.
3. **Contraposición de la evidencia:** cada postura clínica se entrega con su balance adverso y las controversias abiertas.
4. **Actualización continua:** ante evidencia nueva, el marco se revisa y se emite una versión actualizada.
